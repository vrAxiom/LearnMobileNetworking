# Contributing to LearnMobileNetworking

Thanks for your interest in contributing.

## Contribution policy

- **Do not push directly to `main`.**
- **All changes must be submitted through a Pull Request (PR).**
- A PR should include a clear description of what changed and why.

## Main branch protection (required)

Repository maintainers should enable branch protection for `main`:

1. Open **Settings** → **Branches**.
2. Under **Branch protection rules**, click **Add rule**.
3. Set branch name pattern to `main`.
4. Enable at least:
   - **Require a pull request before merging**
   - **Require approvals** (recommended: at least 1)
   - **Restrict who can push to matching branches** (optional but recommended)
   - **Do not allow bypassing the above settings** (recommended)
5. Save changes.

## Pull request checklist

- Keep changes focused and minimal.
- Update documentation when behavior/content changes.
- Confirm the page works by opening `index.html` in a browser.
- Request review before merge.
