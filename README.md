# 📡 LearnMobileNetworking

An interactive, single-page learning hub covering the full Mobile Network Architecture & Data/Voice Transport curriculum — from analog 1G to cloud-native 5G.

Built as an intern training guide for anyone entering the mobile telecommunications industry.

---

## 🌐 Live Demo

Open `index.html` in any browser — no server, no dependencies, works fully offline.

---

## 📚 What's Inside

### 4 Sections

| Section | Description |
|---|---|
| **Overview** | Hero stats + all 7 chapter cards + recommended learning path |
| **Concept Map** | Click any chapter → drill-down with flow diagram, SVG architecture diagram, 6 key concepts, and key terms |
| **Quiz** | 28 multiple-choice questions with per-chapter filtering, instant feedback, and live score bar |
| **Glossary** | 50+ terms with instant search |

### 7 Chapters

| # | Chapter | Topics |
|---|---|---|
| 1 | Evolution of Mobile Networks | 1G → 2G → 3G → 4G → 5G, GPRS, Massive MIMO, Beamforming |
| 2 | Anatomy of a Mobile Network | RAN, UE, eNodeB, gNodeB, EPC, MME, S-GW, P-GW, 5GC, AMF, SMF, UPF |
| 3 | Protocol Stack | GTP, SDAP, PDCP, RLC, MAC, PHY, OFDM |
| 4 | Voice Call Routing | Circuit Switched, VoLTE, IMS, CSFB, SRVCC, VoNR |
| 5 | Data Transfer & Video Streaming | HTTP/3, QUIC, MEC, ULCL, DASH, Google Global Cache |
| 6 | QoS & Network Slicing | QCI, 5QI, eMBB, URLLC, mMTC, Network Slicing |
| 7 | Mobility & Handover | Hard Handover, Dual Connectivity, Beam Management, X2/Xn Interface |

## 🏗️ Tech Stack

- **Pure HTML/CSS/JS** — zero frameworks, zero build steps
- **SVG diagrams** — custom-drawn architecture diagrams per chapter
- **Google Fonts** — Space Mono + DM Sans
- **Self-contained** — single `index.html` file, ~70 KB

---

## 🚀 Deploy to GitHub Pages

1. Go to your repo → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / `root`
4. Save — your site will be live at `https://<username>.github.io/LearnMobileNetworking`
